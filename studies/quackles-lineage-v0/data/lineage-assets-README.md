# Quackles lineage image derivatives

Public web derivatives for the Quackles `/lineage/` archive. No source files, source paths, scene files, EXIF, or private review records are included.

- Snapshot: 2026-10-15; 665 deduplicated historical versions across Day, White, Blue, Dark and Night, plus the five references and exact current selections.
- Dataset SHA-256: `7caa37042011fc09e1f25ca29b2e6ab8ba655d0f028a02212296f0b23b0a1087`.
- `v1/<sha256-prefix>.webp`: each filename is the first 24 hex characters of the encoded image's SHA-256. Identical output bytes share one file.
- Small / large: maximum long edge 288 / 576 px, WebP quality 66 / 70. Combined unique thumbnail bytes: **15,859,482**.
- Medium: maximum long edge 1024 px, WebP quality 79. Unique medium bytes: **43,761,394**; requested only when opening a lightbox.
- 2,019 unique encoded image files. The site's versioned JSON supplies the variant keys and exact dimensions. Taller original plates are retained uncropped.

Generated by the site's `scripts/build_lineage.py` using Pillow. The public manifest is an allowlisted projection, not a redacted copy of the private archive. References are art direction; current picks are working review selections, not release approval.
