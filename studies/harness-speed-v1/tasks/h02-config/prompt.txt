Extend the cfg package. (1) Values may reference environment variables as ${NAME} or ${NAME:-default}; `$$` is a literal `$`; a missing variable without a default raises ConfigError. Put the expansion in a new module cfg/interp.py exposing expand(value, env) -> str. load_string(text, base_dir='.', env=None) and load_file(path, env=None) take an env mapping that defaults to os.environ. (2) A line `@include <path>` (at top level or inside a section) loads another file, resolved relative to the directory of the including file (base_dir for load_string), and merges its sections into the result at that point: later keys override earlier ones, and the current section is unchanged after the include. Include cycles raise ConfigError. Make `python3 -m unittest` pass. Do not modify the tests.
