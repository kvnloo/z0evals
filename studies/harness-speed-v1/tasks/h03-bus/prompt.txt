Extend bus.Bus. (1) subscribe(topic, handler, priority=0) returns a Subscription object with a cancel() method (calling it twice is harmless); handlers run in descending priority, ties in subscription order. (2) A subscription topic may use `*` to match exactly one dot-separated segment and `#`, only as the last segment, to match one or more segments: `orders.*` matches `orders.new` but not `orders.new.eu`; `orders.#` matches both but not `orders`. Put the matching in a new module bus/match.py with matches(pattern, topic) -> bool. (3) publish(topic, payload) calls every matching handler even if some raise; if any raised, after all handlers ran it raises bus.errors.PublishError (new module) whose .errors attribute lists the raised exceptions in call order. publish returns the number of handlers called. Make `python3 -m unittest` pass. Do not modify the tests.
