# z0evals roadmap

The roadmap is maintainer-owned. Issues become worker-claimable only after triage.

## P0 — freeze the first reproducible study

- Import and review `slm-router-v0` from pinned local DSH commits.
- Regenerate all reported tables from public machine-readable artifacts.
- Preserve known gaps: real served-model composition sweep and authentic multi-turn orchestration evaluation unless new evidence resolves them.

## P1 — publication quality

- Research-report shell with strong long-form typography, section navigation, breakout evidence blocks, responsive tables, and interactive-figure hooks.
- Publish the first evidence-led routing report after the study is frozen.

## P2 — evaluation platform

- Q-Route v0: frozen contextual routing evaluation with quality/latency/cost/tail-risk axes.
- Common figure/data bundle format so posts can expose downloadable plotted values.
- Cross-study index and provenance graph.

## Non-goals

- production routing
- experiment orchestration
- token/cost measurement ownership
- model promotion authority
